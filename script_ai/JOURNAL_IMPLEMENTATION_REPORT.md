#### 1. Создан новый Blade шаблон: `resources/views/receipts/journal.blade.php`
- Полная версия журнала приходов с интерфейсом из Figma
- Компоненты:
  - **Статистика** (3 карточки):
    - Всего операций (количество)

    - Типов компонентов (уникальных видов)
  - **Фильтры и поиск**:
    - Кнопки периода: "Все время", "Сегодня", "Неделя", "Месяц"
    - Поле поиска по компоненту или примечаниям
  - **Таблица "Журнал операций"**:
    - Номер документа (формат ПР-YYYY-XXX)
    - Дата операции
    - Позиций (количество товаров в документе) - синяя бейдж
    - Всего единиц (общее количество) - зеленая бейдж
    - Примечания (комментарии)
    - Действия (кнопка просмотра)
- Все стили используют `receipts-*` CSS классы из `resources/css/receipts.css`
- Полностью семантический HTML без Tailwind

#### 2. Расширен `ReceiptController` новым методом
```php
public function journal()
```
- Получает все приходы с типом `IN` из `stock_movements`
- Группирует по дате создания
- Подсчитывает:
  - Общее количество операций
  - Общее количество компонентов
  - Количество уникальных типов
  - Количество позиций в каждом документе
  - Общее количество единиц в документе
- Проводит простую пагинацию (10 документов на странице)

#### 3. Добавлен новый маршрут
```
GET /receipts/journal → receipts.journal (ReceiptController@journal)
```
- Работает вместе с существующими маршрутами приходов
- Полностью интегрирован в роутинг приложения

### Структура данных

Каждый документ в журнале содержит:
```php
[
    'id' => 1,
    'date' => '25.01.2025',           // Отформатирована дата
    'items_count' => 3,                // Количество позиций в документе
    'total_quantity' => 135,           // Сумма всех единиц

]
```
