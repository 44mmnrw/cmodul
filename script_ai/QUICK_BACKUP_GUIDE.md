# 📋 Быстрая инструкция: Резервное копирование БД Cmodul

## ✅ Система полностью готова к использованию!

Все необходимые компоненты установлены и подключены:
- ✅ MySQL 8.4.3
- ✅ mysqldump
- ✅ Подключение к БД успешно
- ✅ БД: `cmodul` (0.52 MB, 16 таблиц)

---

## 🚀 Быстрый старт

### 1️⃣ Создать бекап

```bash
php script_ai/backup_database.php
```

**Результат:** Создается SQL файл типа `cmodul_2026-01-28_09-56-41.sql` в папке `script_ai/backups/`

---

### 2️⃣ Просмотреть доступные бекапы

```bash
php script_ai/restore_database.php
```

**Результат:** Показывает список всех доступных бекапов с номерами

---

### 3️⃣ Восстановить из бекапа

```bash
php script_ai/restore_database.php 1
```

**Результат:** Восстанавливает БД из выбранного бекапа (требуется подтверждение)

---

### 4️⃣ Автоматический бекап с ротацией

```bash
# Создает бекап и хранит последние 7 копий
php script_ai/auto_backup_database.php

# Создает бекап и хранит последние 10 копий
php script_ai/auto_backup_database.php 10
```

**Результат:** Новый бекап + автоматическое удаление старых копий

## 🔧 Автоматизация через Task Scheduler (Windows)

Создайте задачу для ежедневного бекапа:

1. Откройте **Task Scheduler** (Планировщик задач)
2. Создайте новую задачу:
   - **Имя:** Cmodul Database Backup
   - **Триггер:** Ежедневно в 2:00 AM
   - **Действие:** Запустить программу
     - **Программа:** `C:\laragon\bin\php\php-8.2.x\php.exe`
     - **Аргументы:** `C:\laragon\www\Cmodul\script_ai\auto_backup_database.php 7`

## ⚠️ Важные примечания

1. **Пароли в скриптах:** Используют данные из `.env` файла (безопасно)
2. **Восстановление:** Текущие данные **ПЕРЕЗАПИСЫВАЮТСЯ** при восстановлении
3. **Хранение:** Бекапы сохраняются в `script_ai/backups/`
4. **Ротация:** Старые бекапы автоматически удаляются, когда превышен лимит
